# 旧リリースビルド方式

このディレクトリには、2026年7月29日まで使用していたリリースビルド方式を保存しています。

`build-release.ps1`はGarbleの対象を限定せず、既定で`-tiny`も使用する旧方式です。`Old`ディレクトリから実行できるよう、リポジトリ位置の解決だけを調整しています。比較・調査用として保持し、通常のリリースには使用しません。

`build-release.snapshot.ps1`は、移動前の旧スクリプトを内容も含めてそのまま保存したスナップショットです。配置階層が変わっているため、こちらは記録専用です。

正式なビルドには、一つ上のディレクトリにある`build-release.ps1`を使用してください。
