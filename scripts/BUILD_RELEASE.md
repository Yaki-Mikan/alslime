# リリースビルド方式

## 正式方式

通常のリリースビルドには`build-release.ps1`を使用します。

- Garbleの対象は`alslime-core/go.mod`に記載されたcoreモジュール全体です。
- 公開側のパッケージ、Goランタイム、外部依存は難読化しません。
- `-literals`、`-seed=random`、`-ldflags="-s -w"`を維持します。
- `-tiny`は既定で使用しません。
- ビルド用のGoキャッシュと一時ディレクトリは、成功・失敗にかかわらず削除します。調査目的で残す場合だけ`-KeepCache`を指定します。

旧方式との比較が必要な場合に限り、`-Tiny`を指定できます。`-NoGarble`はローカル診断専用であり、作成したバイナリは配布しません。

## 旧方式

以前の「全パッケージをGarbleの対象とし、`-tiny`も既定で使用する方式」は`Old`ディレクトリに保存しています。

- `Old/build-release.ps1`: `Old`ディレクトリから実行できる旧方式
- `Old/build-release.snapshot.ps1`: 移動前の内容をそのまま保持した記録用スナップショット
