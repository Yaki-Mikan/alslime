# AlSlime 操作マニュアル

AlSlime の導入から各機能の使い方までをご案内いたします。

English version: [English version is here](en/index.md)

## はじめて使う方へ（読む順番）

1. [01 導入と起動](ja/01-setup.md) — 入手から起動、利用規約への同意まで
2. [02 画面の見かた](ja/02-screen.md) — 画面の構成と会話画面の見出しのボタン
3. [03 はじめての会話](ja/03-first-chat.md) — 会話の開始から応答に対する操作まで

会話の設定を詳しく調整する場合は、次に [04 準備・調整：キャラクター](ja/04-prepare-characters.md)、[05 準備・調整：場面・文体・プリセット](ja/05-prepare-scene.md)、[06 会話を続ける](ja/06-continue.md)、[07 素材づくり](ja/07-material.md) の順に参照します。

支援者機能の利用方法は [09 支援者機能](ja/09-sponsor.md) で説明します。画像生成は [10 画像生成](ja/10-image-generation.md) と [07-3 素材づくり：キャラ](ja/07-material-characters.md)〜[07-5 素材づくり：タグと画像生成](ja/07-material-image.md)、読み上げは [11 読み上げ](ja/11-tts.md) と [07-3 素材づくり：キャラ](ja/07-material-characters.md)・[07-4 素材づくり：声](ja/07-material-voice.md) で説明します。

## 本マニュアルについて

- 画面写真は開発中の版で撮影したものを含み、実際の表示と異なる場合があります。
- 誤りや分かりにくい箇所についてのご連絡は、[Issue](https://github.com/Yaki-Mikan/alslime/issues) にて受け付けております。
