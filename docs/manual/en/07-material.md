# 07 Materials

This chapter gives an overview of the "Materials" screen and the contents of each page.

## What This Chapter Covers

1. The Materials screen
2. Types of tabs and when they are shown
3. Opening Materials from other screens

## 1. The Materials Screen

Select "Materials" on the navigation bar to show the Materials screen. When it is opened from the navigation bar, the "Settings files" tab is always selected first.

![The Materials tabs](../images/ja/07-01-tabs.png)

Next to the heading are tabs for each type of material.

## 2. Types of Tabs and When They Are Shown

| Tab | Description | When it is shown | Details |
| --- | --- | --- | --- |
| Settings files | Creating and editing settings files for characters, scenes, styles, and more, and creating settings files with AI | Always | [07-1 Settings Files](07-material-files.md), [07-2 Create with AI](07-material-ai-create.md) |
| Characters | Image settings for each character, expression images, "Test generation", and voice links | When the image generation or text-to-speech supporter feature is enabled | [07-3 Characters](07-material-characters.md) |
| Voices | Registering voices used for text-to-speech and testing the reading | When the text-to-speech supporter feature is enabled | [07-4 Voices](07-material-voice.md) |
| Tags | Registering and editing the tags used for image generation | When the image generation supporter feature is enabled | [07-5 Tags and Image Generation](07-material-image.md) |
| Image generation | Managing workflows and generation presets | When the image generation supporter feature is enabled | [07-5 Tags and Image Generation](07-material-image.md) |

When the supporter features are disabled, no tabs are shown and only the settings files screen is shown. If the state of the supporter features changes and the selected tab is no longer available, the "Settings files" tab is selected. Supporter features are explained in [09 Supporter Features](09-sponsor.md).

## 3. Opening Materials from Other Screens

The Materials screen can also be opened from the following places. In each case, it opens with the relevant tab and item selected.

- "Settings file", "Image settings", "Voice settings", and "Open in Materials" in the character details of the Setup panel ([04 Setup: Characters](04-prepare-characters.md))
- "Open characters", "Open voices", "Open tags in Materials", and "Open workflows in Materials" in "Image & voice" on the Settings screen ([08 Settings](08-settings.md))
- "Edit in Materials" in "Tag enable/disable settings" of Quick settings ([10 Image Generation](10-image-generation.md))
