# 10 音声読み上げ（Irodori-TTS 連携・支援者向け）

[目次に戻る](../index.md)

キャラクターの返答を、AI 音声合成 Irodori-TTS に読み上げてもらう、支援者向けの機能です。参照音声から声を作り、キャラクターごとに割り当てて、会話をそのまま声で聴けます。

> **対応言語のご案内**
>
> Irodori-TTS が読み上げられるのは日本語のみです。また、モジュールの取得と、チャット画面左メニューの音声読み上げパネルは、表示言語が日本語のときに表示されます。

![読み上げボタンの付いた会話画面](../images/ja/10-00-tts-chat-result.png)

セリフのひとつひとつに声が乗ると、会話のひとときがまた少し近くなります。この章では、お好みの声で会話を聴けるようになるまでの準備をご案内します。

## この章でご案内すること

1. Irodori-TTS-Server と AlSlime の役割を知る
2. Irodori-TTS-Server を用意する
3. AlSlime との接続を確かめる
4. ボイスを用意し、キャラクターへ割り当てる
5. 読み上げテストで確かめる
6. 会話を読み上げる

## はじめに

音声を実際に生成するのは Irodori-TTS-Server です。AlSlime は、応答をセリフのまとまりごとに区切り、キャラクターに割り当てた声で Irodori-TTS-Server へ生成をお願いします。できあがった音声は AlSlime が受け取り、会話の該当メッセージから再生できます。

### 前提条件

- [08 支援者機能](08-sponsor.md)の手順を済ませ、Irodori-TTS連携モジュールが「有効（サイドカー動作中）」になっていること
- Irodori-TTS-Server がご自身の環境に導入済みで、起動していること
- GPU を推奨します。VRAM が少ない環境向けには量子化版モデルもあります
- 画像生成（ComfyUI）と同時に使う場合は VRAM を取り合うため、余裕のある構成にしてください
- 表示言語が日本語であること（モジュールの取得に必要です）

参照音声から声を作る際の注意については、[ボイスを作成する](10-tts-voice.md)の冒頭を先にご覧ください。

## 1. まずはひととおり準備する

初めてお使いになるときは、次の順で進めていただくと分かりやすいでしょう。

1. [08 支援者機能](08-sponsor.md)の案内に沿って、Irodori-TTS連携モジュールをダウンロードします。
2. Irodori-TTS-Server をご自身の環境へ導入し、起動します。
3. AlSlime の「TTS設定」で、Irodori-TTS-Server との接続を確かめます。
4. 参照音声からボイスを登録します。
5. キャラクターへボイスを割り当てます。
6. 読み上げテストで仕上がりを確かめます。
7. 会話に戻り、応答の「読み上げ」からお試しください。

モジュールのカードには、ご利用前の注意もまとめてあります。

![Irodori-TTS連携モジュールのカード](../images/ja/10-01-sponsor-tts-module.png)

## 2. Irodori-TTS-Server を用意する

Irodori-TTS-Server は外部ツールです。構築と起動はご自身の環境で行っていただきます。サーバーは次の 2 つからお選びいただけます。

| 選択肢 | 説明 |
| --- | --- |
| AlSlime 向けフォーク版（推奨） | [Irodori-TTS-Server-AlSlime](https://github.com/Yaki-Mikan/Irodori-TTS-Server-AlSlime)。AlSlime の全機能をご利用いただけます |
| 公式版 | 公式の Irodori-TTS-Server です。基本の音声生成はご利用いただけますが、次の機能は使えません |

公式版に接続した場合、AlSlime が自動で判定し、次の機能を無効にします。

- 日本語の Voice ID（公式版は半角英数のみ）
- Latent ファイルの直接登録
- エンジン管理（モデルの切り替え・省メモリモード・サーバー再起動）

### フォーク版の導入と起動

1. [Irodori-TTS-Server-AlSlime のページ](https://github.com/Yaki-Mikan/Irodori-TTS-Server-AlSlime)を開き、「Code」→「Download ZIP」でダウンロードします。
2. ダウンロードした ZIP を、お好みの場所へ展開します。
3. 展開したフォルダー内の `start_irodori_server.bat` をダブルクリックします。

初回は、実行環境の構築とモデルなどのダウンロードが自動で行われるため、時間がかかります。2 回目以降は構築を省略してすぐに起動します。

NVIDIA 以外の GPU や Linux でお使いの場合の導入方法は、リポジトリの README をご覧ください。コマンドで導入する場合の環境の選び方は次のとおりです。

| 環境 | コマンド |
| --- | --- |
| NVIDIA CUDA | `uv sync --extra cu128` |
| AMD ROCm（Linux） | `uv sync --extra rocm` |
| CPU のみ | `uv sync --extra cpu` |

## 3. AlSlime と接続する

開き方: 設定ファイルエディタ →「TTS設定」タブ。設定（歯車）→「TTS設定」からも開けます。

「TTS設定」は、支援者機能と Irodori-TTS連携モジュールが有効な場合に表示されます。

![TTS統合設定の接続設定](../images/ja/10-02-tts-connection.png)

1. 「接続設定」の「エンドポイントURL」に、起動中の Irodori-TTS-Server の URL をご入力ください。初期値は `http://127.0.0.1:8088` です。
2. 「接続を確認」を選び、「接続できました」と表示されることをお確かめください。サーバー応答・モデル一覧・Voice一覧の 3 点が確認されます。

同じ PC で通常の設定のまま Irodori-TTS-Server をお使いなら、初期値のままで接続できます。別 PC 上のサーバーへ接続する場合の APIキーなどは、[設定項目の詳細](10-tts-settings-details.md)をご覧ください。

## 4. ボイスを用意する

声の用意には 2 つの方法があります。

- **参照音声から作る**: お手元の音声ファイルから声質を写し取り、ボイスとして登録します。
- **VoiceDesign で言葉から設計する**: 「落ち着いた低めの女性の声」のように、文章で声質を指定します。

手順は[ボイスを作成する](10-tts-voice.md)でご案内しています。参照音声の扱いに関する注意も、あわせてご覧ください。

## 5. キャラクターに声を割り当てる

登録したボイスをキャラクターへ割り当てると、そのキャラクターのセリフが割り当てた声で読み上げられます。

開き方は、次のどちらでもかまいません。

- 「TTS設定」→「キャラクター割り当て」
- 会話設定サイドバーのキャラクター枠にある音声設定アイコン

![会話設定サイドバーの音声設定アイコン](../images/ja/10-14-tts-voice-panel.png)

![キャラクター割り当て](../images/ja/10-08-tts-char-assign.png)

1. 「キャラクター」でキャラクターを選びます。
2. 「Voice」で割り当てるボイスを選びます。
3. 「保存」を選びます。

「このキャラで試聴」で、割り当てた声をすぐに確かめられます。VoiceDesign キャプションなどの項目は、[ボイスを作成する](10-tts-voice.md)をご覧ください。

## 6. 読み上げテストで確かめる

会話で使う前に、「読み上げテスト」でひとこと試しておくと安心です。

![読み上げテスト](../images/ja/10-09-tts-test.png)

1. 「TTS設定」右側の「読み上げテスト」に、テスト用テキストを入力します。
2. 「テストする音声」で、ボイスまたは選択中のキャラクターを選びます。
3. 「テスト」を選びます。
4. 生成が終わったら「再生」でお聴きください。

初めての生成では、Irodori-TTS-Server がモデルを自動で読み込むため、時間がかかります。2 回目からは短くなります。

## 7. 会話を読み上げる

準備が整いましたら、会話へ戻って聴いてみましょう。読み上げの開始には 2 つの方法があります。

### セリフのまとまりごとに読み上げる

キャラクターの発言のまとまり（吹き出し）ごとに、「読み上げ」ボタンが付いています。

![発言ごとの読み上げボタン](../images/ja/10-10-tts-turn-button.png)

1. 聴きたい発言の「読み上げ」を選びます。
2. 生成中はボタンが「キャンセル」に変わります。そのまま少しお待ちください。
3. 生成が終わると「再生」ボタンが現れます。時間表示とあわせてお聴きください。

![生成済みの発言（再生・再作成）](../images/ja/10-15-tts-turn-generated.png)

生成済みの発言は「再作成」で作り直せます。

### 応答全体をとおして読み上げる

応答の下部にある「全体読み上げ」を選ぶと、その応答のすべての発言を順に生成し、続けて再生します。

![応答下部の全体読み上げ](../images/ja/10-11-tts-readall-button.png)

生成中は「全体読み上げ」が「キャンセル」に変わります。とおし再生の間、個々の発言の操作はお休みになります。再生を止めてから操作してください。

![全体読み上げの生成中](../images/ja/10-12-tts-generating.png)

生成した音声は会話セッションとメッセージに結び付けて保存されるため、同じセッションを開き直したときにも再生できます。不要になった音声は、発言の「音声を削除」から削除できます。

### 自動で読み上げる

チャット画面左上のメニューを開き、「音声読み上げ」パネルの「自動読み上げ」を有効にすると、新しい応答が届くたびに自動で音声を作ります。「応答時に音声も再生する」もあわせて有効にすると、そのまま再生されます。

![左メニューの音声読み上げパネル](../images/ja/10-13-tts-drawer.png)

このパネルでは、読み上げ範囲や再生音量などもその場で調整できます。項目の内容は[設定項目の詳細](10-tts-settings-details.md)をご覧ください。

## 8. 絵文字で感情を乗せる

「TTS設定」右上の「文体指示（絵文字による感情表現）」を有効にすると、AI が応答の文へ対応絵文字を添えるようになり、読み上げ音声へ感情や話し方の調子が乗ります。

絵文字は音声の演技指示としてだけ使われ、画面の表示と画像生成からは常に取り除かれます。対応絵文字の一覧と仕組みは、[設定項目の詳細](10-tts-settings-details.md)をご覧ください。

## 9. 設定を残しておく

絵文字の説明ファイルなどの付属ファイルは、[07 設定のインポート / エクスポート](07-settings-pack.md)の「音声読み上げ（Irodori-TTS）付属ファイル」として書き出せます。

接続設定はお使いの環境に依存するため、設定パックには含まれません。お引っ越しの際は、接続先の URL を新しい環境で入力し直してください。

## うまくいかないとき

- **「TTS設定」や読み上げボタンが見当たらない**: [08 支援者機能](08-sponsor.md)を開き、Irodori-TTS連携モジュールが「有効（サイドカー動作中）」になっているかお確かめください。モジュールの取得には表示言語を日本語にする必要があります。
- **接続の確認に失敗する**: Irodori-TTS-Server が起動しているか、エンドポイントURL とポートがサーバー側と同じかをご確認ください。
- **「音声が紐づいていません」と表示される**: そのキャラクターにボイスが割り当てられていません。[5. キャラクターに声を割り当てる](#5-キャラクターに声を割り当てる)をご覧ください。
- **音声ができるまで時間がかかる**: 初回はモデルの読み込みが加わります。また、画像生成と同時に使うと VRAM を取り合い、遅くなることがあります。
- **mp3 を選ぶと失敗する**: Irodori-TTS-Server 側に mp3 エンコーダー（FFmpeg）が必要です。
- **エンジン管理の項目が使えない**: 公式版サーバーに接続しています。フォーク版をご利用ください。
- そのほかについては、[11 困ったときは](11-troubleshooting.md)をご覧ください。
