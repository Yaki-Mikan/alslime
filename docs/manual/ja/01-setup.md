## 1. 動作環境

- **OS**: Windows / Linux
- **ブラウザ**: Chrome・Edge・Firefox などの一般的なブラウザ
- **AI**: 次のいずれか
  - AI の CLI（Antigravity CLI・Gemini CLI・Claude Code）
  - OpenAI 互換の API を提供する AI サービス

### AI の準備

AlSlime の会話には、次のいずれかの AI サービスを使用します。各サービスの契約と対応する CLI または API キーを用意し、AlSlime を起動します。

| 使用する AI | 契約 | 用意するもの |
| --- | --- | --- |
| Gemini（Google）・個人契約 | Google AI Pro / Ultra のサブスクリプション | **Antigravity CLI**（コマンド名 `agy`） |
| Gemini（Google）・企業契約 | 企業向け Gemini Code Assist（Standard など） | **Gemini CLI**（コマンド名 `gemini`） |
| Claude（Anthropic） | Claude の対応有料プラン（Max など） | **Claude Code**（コマンド名 `claude`） |
| API で提供される AI サービス | OpenRouter・OpenAI・DeepSeek・OpenCode Go などの API の契約 | 各サービスの API キー |

- CLI は、導入後にターミナルで一度起動し、ログインを完了した状態で使用します。~~入手からログインまでの手順は、AlSlime のホームページにてご案内しております。~~（現在鋭意作成中）
- API は、AlSlime の起動後に接続先を登録して使用します（[08 設定](08-settings.md)）。API の利用料金は、各サービスとの契約に基づいて発生します。
- 対応プランや料金は、提供元の都合により改定される場合があります。
- Gemini CLI の個人向けのログイン方法（Google AI Pro / Ultra・個人向け Gemini Code Assist）は、2026 年 6 月 18 日をもって終了しています。個人契約で Google の AI を使用する場合は、後継の Antigravity CLI を使用します。

## 2. AlSlime の入手

GitHub Releases より、使用する OS に対応したファイルをダウンロードし、展開します。

- **Windows**: `alslime-X.Y.Z-windows-amd64.zip` を展開します。本体の `alslime.exe` と起動用の `start-alslime.bat` が同梱されています。
- **Linux**: `alslime-X.Y.Z-linux-amd64.tar.gz` を展開します（`tar xzf alslime-X.Y.Z-linux-amd64.tar.gz`）。実行権限は付与済みのため、展開後はそのまま起動が可能です。

いずれのファイルにも、利用規約・ライセンス・README（日本語・英語）を同梱しております。支援者向けのモジュールは、起動後に別途ダウンロードする形式となります（[09 支援者機能](09-sponsor.md)）。

## 3. 起動と画面の表示

### 起動する場所について

AlSlime は会話の記録や設定をデータフォルダに保存します。保存先の確認方法は [13 データの置き場所とバックアップ](13-data.md) で説明します。展開したファイル一式は、専用のフォルダに配置した状態での使用を想定しております。

### 起動の手順

起動すると、お手元の PC の中だけで動作する AlSlime の本体が立ち上がり、ブラウザで画面を表示する準備が整います。

- **Windows**: `start-alslime.bat` をダブルクリックします。本体が起動し、3 秒ほど経過すると、ブラウザに画面が表示されます。
- **Linux**: `./alslime` を実行します。デスクトップ環境では、ブラウザが自動的に起動し、画面が表示されます。

本体の動作中は、コンソールに画面のアドレスが表示されます。

> **画面が表示されない場合**
>
> - 接続エラーのページが表示された場合は、本体の起動完了前にブラウザが起動した可能性があります。少し時間をおいてから再読み込みを行うと、画面が表示されます。
> - ブラウザが起動しない場合は、コンソールに表示されたアドレス（通常は `http://127.0.0.1:3000`）をブラウザに直接入力すると、画面が表示されます。
> - Windows で `alslime.exe` を直接起動した場合、ブラウザの自動起動は行われません。この場合も、アドレスの直接入力により画面が表示されます。
> - 上記で解消しない場合の確認事項は、[14 困ったとき](14-troubleshooting.md) に記載しております。

## 4. 利用規約への同意

初回起動時には、「利用規約への同意」の画面が表示されます。

![利用規約への同意の画面](../images/ja/01-01-eula-gate.png)

1. 見出しの下の欄では、表示言語（日本語 / English）の切り替えが可能です。
2. 次の 3 つの確認項目を読み、内容に同意する場合は、それぞれのチェックボックスを選択します。
   - 私は18歳以上です。
   - 出力は私が接続した外部AIサービスが生成するものであり、開発者は内容に関与しないことを理解しました。
   - 本ソフトウェアは無保証（AS IS）で提供され、医療・相談用途ではないことを理解しました。
3. 「利用規約全文を読む」を選択すると、規約の全文がその場に表示されます。日本語以外の表示言語では、日本語版を正文とする旨の注記もあわせて表示されます。

   ![利用規約の全文を表示した状態](../images/ja/01-02-eula-fulltext.png)

4. 3 つすべてのチェックボックスを選択すると、「同意して開始」が選択可能となります。「同意して開始」を選択します。

なお、利用規約の改定時やデータを保存するフォルダの変更時には、改めて同意の画面が表示されます。

## 5. 初回の画面

同意が完了すると、会話の画面が表示されます。初回は、会話の準備を行う「準備・調整」の欄が右側に表示されています。

![同意後に表示される最初の画面](../images/ja/01-03-first-view.png)

画面の構成については [02 画面の見かた](02-screen.md)、会話の開始方法については [03 はじめての会話](03-first-chat.md) にてご案内いたします。

## 6. 公式サンプルの取り込み

公式サンプルには、キャラクター・テンプレート・プリセットの一式を収録しております。取り込んだ時点で、設定ファイルを作成せずに会話を開始する準備が整います。

1. 画面左端の「設定」を選択します（画面の幅が狭い場合は、画面下部のタブにある「設定」となります）。
2. 「公式サンプル」を選択します。
3. 「設定サンプル一式」の「ダウンロードして取り込む」で、「実行」を選択します。

   ![公式サンプルの取り込み](../images/ja/01-04-official-samples.png)

サンプルは GitHub からダウンロードのうえ取り込まれ、既存のファイルは変更されません。同じ画面では、設定自動生成用テンプレートも取り込めます。詳細は、[08 設定](08-settings.md) にてご案内いたします。

## 7. CLI の場所の指定

AI の CLI は、通常であれば AlSlime が自動的に検出します。メッセージの送信時にエラーが表示される場合や既定とは異なる場所へ CLI を導入した場合は、実行ファイルの場所を指定します。

1. 「設定」から「起動・システム」へ進みます。
2. 「CLI 実行ファイルパス」のうち、使用する CLI の欄へ実行ファイルの場所を入力します。空欄の CLI は、引き続き自動で検出されます。
3. 欄の横にある「疎通確認」を選択すると、入力した場所から CLI が起動するかが確認され、その結果が CLI 名の下に表示されます。保存前の入力内容でも確認が可能です。

   ![起動・システムの画面（起動設定と CLI 実行ファイルパス）](../images/ja/01-05-startup-system.png)

   | 表示 | 意味 |
   | --- | --- |
   | 起動できました | CLI の起動を確認しました。CLI 名と版も表示されます |
   | 既定のインストール先とPATHのどちらにも見つかりませんでした。 | 自動検出の対象となる場所に、CLI が存在しない状態です |
   | 指定したパスに実行できるファイルがありません。 | 入力した場所に、実行ファイルが存在しない状態です |
   | 起動に失敗しました。 | 実行ファイルは存在するものの、起動の途中で停止した状態です |
   | 制限時間内に応答がありませんでした。 | CLI から時間内に応答がなかった状態です |

4. 画面下部に表示される「保存」を選択します。保存した内容は、次に AI を呼び出した時点から反映されます。本体の再起動は不要です。

## 8. 起動設定の変更

「設定」の「起動・システム」にある「起動設定」（前項の画面の上段）では、画面を表示するアドレスなどを変更します。**変更内容は、次回の起動時から反映されます。**

- **ポート**: 画面を表示するアドレスのポート番号です。初期値は 3000 です。
- **待受アドレス**: 初期状態は、この PC からの接続に限った設定です。
- **LAN公開**: 同じネットワーク内のスマートフォンなど、ほかの端末からの接続を許可する設定です。

> **LAN公開を有効にする際のご注意**
>
> AlSlime は、お手元の PC での利用を前提に、ログインを介さずに画面を表示する構成としております。LAN公開を有効にすると、同じネットワークに接続しているどなたでも、会話の記録や設定を閲覧し、AI を使える状態となります。LAN公開は、ご自宅のような信頼できるネットワークでの利用を想定した機能です。

- Windows でポートを変更した場合は、`start-alslime.bat` 内のアドレスも同じポート番号に書き換えます。書き換えない場合はブラウザで変更前のアドレスが開かれます。

## 9. 終了の方法

AlSlime の本体は、ブラウザの終了後も動作を継続します。終了の際は、次の操作を行います。

- **Windows**: コンソールのウィンドウを終了するか、コンソール上で Ctrl + C を入力します。
- **Linux**: 起動した端末で Ctrl + C を入力します。

実行中の処理がある場合は、その完了をわずかに待ってから終了します。

## 起動直後に終了してしまう場合

起動後すぐに終了してしまう場合、次のような原因が考えられます。

- ほかのアプリケーションが同じポートを使用している
- 起動設定の内容が破損している
- 起動したフォルダへの書き込みが許可されていない

Windows では、コンソールのウィンドウが即座に終了し、表示内容の確認が難しい場合があります。原因の確認方法は、[14 困ったとき](14-troubleshooting.md) にてご案内いたします。
