# 03 はじめての会話

[目次に戻る](../index.md)

前章: [02 画面の見かた](02-screen.md) ／ 次章: [04 準備・調整：キャラクター](04-prepare-characters.md)

本章では、キャラクターを選択して会話を開始し、応答を受け取るまでの手順と会話の画面で行う主な操作についてご案内いたします。

## この章の内容

1. 会話の開始までの手順
2. メッセージの入力と送信
3. 使う AI とモデルの選択
4. 応答に対する操作

## 1. 会話の開始までの手順

会話は、次の 3 つの手順で開始します。

1. 「準備・調整」の欄の「キャラ」タブで、「キャラを追加」を選択します。
2. 表示された「キャラクターを選択...」の窓で、会話の相手となるキャラクターを選択します。

   ![キャラクターを選択する窓](../images/ja/03-01-character-select.png)

   - 上部の検索欄では、キャラクターの名前による絞り込みが可能です。
   - 「作品」では、作品ごとの絞り込みが可能です。「未分類」を選択すると、作品が設定されていないキャラクターが表示されます。
   - タグを複数選択すると、選択したタグをすべて持つキャラクターに絞り込まれます。
   - 同じ会話にすでに追加しているキャラクターは一覧に表示されません。

3. 欄の下部にある「会話開始」を選択します。

会話を開始すると、画面中央に「チャットでメッセージを送って会話を始めてください。」と表示されます。続いて、画面下部の入力欄にメッセージを入力し、送信します。

- 1 つの会話には、最大 5 人のキャラクターが参加します。
- 場面や文体の設定は任意です。設定方法は [05 準備・調整：場面・文体・プリセット](05-prepare-scene.md) にてご案内いたします。
- キャラクターごとの詳細な設定は、[04 準備・調整：キャラクター](04-prepare-characters.md) にてご案内いたします。

## 2. メッセージの入力と送信

入力欄の右下にある送信ボタンを選択すると、メッセージが送信されます。入力欄の高さは、入力した行数に応じて自動的に調整されます。メッセージが未入力で行動の候補も選択していない場合は、送信ボタンが無効になります。

### 送信キー

キーボードでの送信には、「設定」の「一般」にある「チャットの送信キー」で選択したキー操作を使用します。

- 選択肢は「Enterキー」「Shift + Enterキー」「Ctrl + Enterキー」の 3 種類で、初期設定は「Shift + Enterキー」です。
- 選択したキー操作以外の Enter キーは、改行として扱われます。
- 日本語入力の変換中に押した Enter キーでは、送信は行われません。
- スマートフォンなどのタッチ操作の端末では、Enter キーは常に改行として扱われます。

### 生成の停止

応答の生成中は、送信ボタンが停止ボタンに切り替わります。停止ボタンを選択すると、生成が中止されます。

## 3. 使う AI とモデルの選択

入力欄の左下には、使用中の AI とモデルの名前が表示されています。この表示を選択すると「使う AI とモデル」の小窓が表示されます。この小窓で会話に使用する AI とモデルを切り替えます。

![使う AI とモデルの小窓](../images/ja/03-02-model-picker.png)

| 項目 | 内容 | 表示される条件 |
| --- | --- | --- |
| 使う AI | 「Antigravity」「Claude」「Gemini」「API（OpenAI互換）」から選択します。切り替えると、既定のモデルが自動的に選択されます | 常に表示 |
| API接続先 | 使用する API の接続先を選択します | 使う AI が「API（OpenAI互換）」の場合 |
| モデル | 使用するモデルを選択します | 常に表示 |
| Claude effort | Claude が応答を生成する際の思考の深さを選択します。選択内容は次回の起動後も維持されます | 使う AI が「Claude」の場合 |
| Antigravity thinking | Antigravity が応答を生成する際の思考の深さを選択します。選択内容は次回の起動後も維持されます | 使う AI が「Antigravity」で、対応するモデルを選択している場合 |
| モデル設定を開く | 「設定」の「AI と接続」を表示します | 常に表示 |

- 使う AI が「Antigravity」の場合は、「呼び出し回数の上限」も表示されます。~~この項目の詳細は、AlSlime のホームページにてご案内しております。~~（現在鋭意作成中）
- 小窓の外を選択するか、Esc キーを押すと、小窓の表示が終了します。
- 起動直後は、「設定」の「AI と接続」で指定した既定の AI とモデルが選択されています。
- 履歴から会話を再開すると、その会話で最後に使用した AI とモデルに切り替わります。
- 「API（OpenAI互換）」では、支援者機能の行動の選択肢は生成されません。
- API の接続先とモデルの登録は、[08 設定](08-settings.md) にてご案内いたします。

## 4. 応答に対する操作

キャラクターの応答は、発言ごとに吹き出しで表示されます。

- キャラクターに表情ごとの画像が登録されている場合は、名前の横に表情に応じたアイコンが表示されます。
- 日付と時刻を会話に含める設定の場合は、発言ごとに会話の中の日時が表示されます。
- 応答の下には、応答の生成に使用したモデルの名前が「Generated by」に続けて表示されます。

![応答の下に並ぶ操作](../images/ja/03-03-message-actions.png)

### 発言の編集

吹き出しの右上にある鉛筆のアイコンを選択すると、発言の本文を編集する欄が表示されます。キャラクターの発言とユーザー自身の発言のいずれも編集が可能です。

- 「保存」を選択すると、編集した本文が保存されます。保存の際に、応答が作り直されることはありません。
- 「キャンセル」を選択すると、編集が取り消されます。
- 画面の幅が広い場合、鉛筆のアイコンは吹き出しにマウスを重ねた際に表示されます。画面の幅が狭い場合は常に表示されます。

### 再生成

最新の応答の下にある「再生成」を選択すると、同じ送信内容から応答を再生成し、元の応答と置き換えます。

### 別モデルで再生成

最新の応答の下にある「別モデルで再生成」を選択すると、モデルの選択欄と「実行」が表示されます。モデルを選択して「実行」を選択すると、そのモデルで応答を作り直し、元の応答と置き換えます。× を選択すると、選択欄の表示が終了します。

![別モデルで再生成の選択欄](../images/ja/03-04-regenerate-with-model.png)

選択欄の「詳細...」を選択すると、プロバイダ・モデル・Claude effort・Antigravity thinking を個別に指定する状態となります。選択欄に表示されるのは、使用可能なモデルが登録されているプロバイダのみです。

### 行動の選択肢（支援者機能）

支援者機能の「行動選択肢」が有効な場合は、最新の応答の下に次の行動の候補が表示されます。

- 候補を選択すると、入力欄が空の状態でも送信が可能となります。入力欄に文章がある場合は、選択した候補と文章の両方が送信されます。
- 選択中の候補をもう一度選択すると、選択が解除されます。
- 「その他（自由入力）」を選択すると、候補を使用しない通常の入力に切り替わります。
- 候補は保存されないため、画面の再読み込みを行うと表示されなくなります。

支援者機能については、[09 支援者機能](09-sponsor.md) にてご案内いたします。

### 応答が返らない場合

応答の取得に失敗した場合は、応答の位置に「エラー:」に続けて内容が表示されます。AI から 10 分間応答がない場合は、タイムアウトとして扱われます。いずれの場合も、「再生成」を選択すると、応答の取得を改めて行います。

そのほかの確認事項は、[14 困ったとき](14-troubleshooting.md) に記載しております。
