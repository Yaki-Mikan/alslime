# 07-2 素材づくり：AI で作る

[目次に戻る](../index.md) ／ [07 素材づくり](07-material.md)

前章: [07-1 素材づくり：設定ファイル](07-material-files.md) ／ 次章: [07-3 素材づくり：キャラ](07-material-characters.md)

本章では、AI がウェブ上の情報を調べながら設定ファイルを作成する「AI で作る」についてご案内いたします。

> **ご注意**
>
> 本機能は試験提供中です。ウェブ上の情報を調査して設定ファイルを作成するため、完了までに数分から数十分を要し、AI サービスの利用量が増える場合があります。作成された内容は完成後の画面で確認・編集します。

## この章の内容

1. 作成の流れ

## 1. 作成の流れ

素材づくりの「設定ファイル」タブで、一覧の上部にある「AI で作る」を選択すると、「AI で作る」の画面が表示されます。

![AI で作るの条件の画面](../images/ja/07-2-01-conditions.png)

- 上部には、「1 条件」「2 調べる」「3 設定を作る」「4 確かめて保存」の手順が並び、済んだ手順には ✓ が表示されます。キャラクター以外の種別と作り方で「まとめて作る」を選択した場合は、「調べる」を省いた 3 つの手順となります。
- 下部の帯の左には「やめて閉じる」と「戻る」（条件の手順では非表示）、右には次の手順へ進むボタンが並びます。処理の実行中は、右のボタンが「中止」に切り替わります。見出しの右の × も、「やめて閉じる」と同じ働きです。
- 右側の「AI の作業経過」には、AI の作業の進み具合が行ごとに表示されます。見出しを選択すると、表示が切り替わります。

AI との対話を通じて内容を調整する場合は、設定ファイルを保存した後、[07-1 素材づくり：設定ファイル](07-material-files.md) の「対話で編集」を使用します。

## 2. 条件の指定

「条件」の手順では、作成する設定ファイルの条件を指定します。

| 項目 | 内容 |
| --- | --- |
| 種別 | 作成する設定ファイルの種別を選択します |
| 使うテンプレート | 作成する設定ファイルの形式を定めたテンプレートを選択します。「（既定）」は既定のテンプレートです |
| 名前 | キャラクターの名前を入力します。キャラクター以外の種別では「ファイル名」となり、保存するファイル名を入力します。いずれも入力が必須です |
| 作品名 | キャラクターが登場する作品の名前を入力します。キャラクターの種別でのみ表示され、入力が必須です |
| 備考 | 作成する設定への要望や指示（例：原作と異なる設定の前提を指定するなど）を 2,000 文字まで記述します |
| 調べる項目／書き込む項目 | 調べる項目（2 段階で作る場合）または書き込む項目を定めた項目のテンプレートを選択します |
| 作り方 | 「2 段階で作る（調べてから作る）」または「まとめて作る」を選択します。キャラクターの種別でのみ表示されます |

- 「使うテンプレート」と「項目のテンプレート」の横の「開いて編集」を選択すると、テンプレートの内容が小窓に表示されます。小窓で「保存」を選択すると、その内容でテンプレートが上書きされます。「キャンセル」または × を選択した場合、編集した内容は破棄されます。小窓の外を選択しても、小窓の表示は終了しません。
- 項目のテンプレートを編集したまま別のテンプレートに切り替えようとすると、置き換えの確認が表示されます。
- 作り方と使う AI には、前回の実行時の値が初期値として設定されます。

条件の指定が済んだら、帯の右の「調べ始める」（2 段階で作る場合）または「設定を作る」を選択します。必須の項目が未入力の場合は、入力を促す表示が出て、処理は開始されません。

同じ名前の調査メモ（2 段階で作る場合）または設定ファイル（まとめて作る場合）がある場合は、処理の開始前に上書きの確認が表示されます。

保存済みの調査メモがある場合は、「保存済みの調査メモから始める」も表示されます。選択すると、新たな調査を行わずに「調べる」の手順へ進みます。

## 3. 使う AI

条件の下部には、通常「使う AI：（プロバイダ）・（モデル）」のみが表示されます。この表示を選択すると、使う AI を選ぶ欄が表示されます。

![使う AI を選ぶ欄](../images/ja/07-2-02-ai.png)

| 項目 | 内容 |
| --- | --- |
| AIプロバイダ | Antigravity・Claude・Gemini から選択します。CLI が検出されないものと疎通確認に失敗したものは選択不可となります |
| 疎通確認 | 選択中のプロバイダの CLI を起動できるか確認します |
| 使用モデル | 使用するモデルを選択します。欄の下には、推奨するモデルの注記が表示されます |
| Effort | Claude が応答を生成する際の思考の深さを選択します。プロバイダが Claude の場合に表示されます |
| Thinking | Antigravity の対応するモデルで、思考の深さを選択します |
| タイムアウト（分） | 処理の制限時間を、1〜60 分の範囲で指定します |

## 4. 調べる

「2 段階で作る」場合は、最初に AI がウェブ上の情報を調べ、その結果を調査メモにまとめます。

![調べている最中の画面](../images/ja/07-2-03-researching.png)

- 調査中は「調べています」と経過時間が表示されます。完了すると調査メモが表示され、作成するキャラクターのフォルダに保存されます。

![調査メモ](../images/ja/07-2-04-memo.png)

- 調査メモは、その場で編集が可能です。「調査メモを保存」または Ctrl+S キーで保存され、保存の状態は「保存済み」「保存していない変更」の札で表示されます。
- 保存済みの調査メモがある場合は、「保存済みの調査メモを使う…」から検索の付いた小窓で調査メモを選択します。選択中の調査メモは、横のゴミ箱のアイコンで確認の後に削除されます。
- 調査メモの下では、「設定作成備考」の書き足し、使うテンプレートの選び直しと編集、使う AI の選び直しが可能です。

内容を確認したら、帯の右の「設定を作る」を選択します。同じ名前の設定ファイルがある場合は、作成の開始前に上書きの確認が表示されます。

## 5. 設定を作る

「設定を作る」の手順では、選択したテンプレートに基づき、AI が設定ファイルを作成します。処理中は「設定を作っています」と経過時間が表示されます。

![設定を作っている最中の画面](../images/ja/07-2-05-generating.png)

作成に失敗した場合は、失敗の理由が表示されます。必要に応じて使う AI を選び直し、帯の右の「同じ条件で再実行」を選択すると、同じ手順から処理が再び実行されます。調べる手順で失敗した場合も、同様に再実行します。

## 6. 確かめて保存

作成が完了すると、「できあがった設定」が「完成」の札とともに表示されます。下部には、保存先のファイル名と種別が表示されます。作成した設定ファイルは、完成の時点で保存されます。

![できあがった設定](../images/ja/07-2-06-result.png)

- 表示された内容は、その場で編集が可能です。
- 「設定ファイルとして開く」を選択するか Ctrl+S キーを押すと「設定ファイル」タブの編集画面に切り替わります。内容を編集していた場合は切り替え前に上書き保存されます。
- 帯の左の「最初から作る」を選択すると、種別・テンプレート・使う AI はそのままで、名前と作成結果が空の状態の「条件」の手順に切り替わります。

## 7. 実行中の扱い

- 処理の実行中にほかのタブや画面へ移動しても、処理は継続されます。完了と失敗は、画面下部の知らせに表示されます。ブラウザのサイトの設定で通知を許可している場合は、ブラウザの通知も表示されます。
- 実行中の処理がある間は、新しい作成は開始されず、「別の設定作成処理を実行中です。」と表示されます。
- 実行中の処理は、ジョブ進行状況にも表示されます（[06 会話を続ける](06-continue.md)）。
