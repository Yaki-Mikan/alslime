# 02 画面の見かた

[目次に戻る](../index.md)

前章: [01 導入と起動](01-setup.md) ／ 次章: [03 はじめての会話](03-first-chat.md)

本章では、AlSlime の画面構成と各部分の役割についてご案内いたします。

## この章の内容

1. 画面の全体構成と切り替え列
2. 画面の幅が狭い場合の表示
3. 会話画面の見出しに並ぶボタン
4. デザインと明るさの変更

## 1. 画面の全体構成

![会話画面の全体](../images/ja/02-01-layout.png)

画面は、大きく次の 3 つの領域で構成されています。

- **左端の切り替え列**: 4 つの画面を切り替えるための列です。
- **中央**: 選択中の画面が表示される領域です。起動直後は会話の画面が表示されます。
- **右側**: 会話の準備を行う「準備・調整」の欄です。会話画面の見出しにある「準備・調整」で表示を切り替えます。

切り替え列に並ぶ 4 つのボタンの役割は、次のとおりです。

| ボタン | 役割 | 詳細 |
| --- | --- | --- |
| 会話 | キャラクターとの会話を行う画面です | [03 はじめての会話](03-first-chat.md) |
| 履歴 | これまでの会話を検索し、続きから再開するための画面です | [06 会話を続ける](06-continue.md) |
| 素材 | キャラクターや場面の設定ファイルなど、会話に用いる素材を作成・編集する画面です | [07 素材づくり](07-material.md) |
| 設定 | アプリケーション全体の設定を変更する画面です | [08 設定](08-settings.md) |

- 「素材」を選択すると、常に「設定ファイル」のタブが表示された状態となります。
- 「設定」を選択すると、常に「一般」の分類が表示された状態となります。
- 設定画面に保存していない変更が残っている状態でほかの画面へ移動しようとすると、「保存する」「破棄する」「戻る」のいずれかを選択する確認が表示されます。

## 2. 画面の幅が狭い場合の表示

スマートフォンなど画面の幅が狭い環境では、切り替え列に代わり、画面下部にタブが表示されます。タブの役割は切り替え列と同じです。

![画面の幅が狭い場合の会話画面](../images/ja/02-02-narrow.png)

- 文字の入力中は、画面下部のタブが一時的に非表示となります。
- 見出しのボタンは、文字を省略したアイコンのみの表示となります。
- 「準備・調整」の欄は会話の上に重なる形で表示され、さらに幅が狭い場合は画面全体に表示されます。

## 3. 会話画面の見出し

会話画面の上部には、会話の題と次のボタンが配置されています。

| 表示・ボタン | 役割 | 表示される条件 |
| --- | --- | --- |
| 題 | 会話の題です。会話の開始前は「新しい会話」と表示されます。題の下には、会話に参加しているキャラクターの名前が表示されます | 常に表示 |
| 鉛筆のアイコン | 題を変更します。Enter キーまたは「保存」で確定し、Esc キーまたは「キャンセル」で取り消します | 会話の保存後。画面の幅が広い場合は、題にマウスを重ねた際に表示されます |
| ○件実行中 | 実行中の処理の件数です。選択すると「ジョブ進行状況」が表示されます（[06 会話を続ける](06-continue.md)） | 実行中の処理がある場合 |
| クイック設定 | 画像生成や読み上げなど、すべての会話に共通する設定を表示します（[10 画像生成](10-image-generation.md)・[11 読み上げ](11-tts.md)） | 支援者機能の画像生成または読み上げが有効な場合 |
| 状態 | キャラクターの状態と、会話の中の時刻を確認する欄を表示します（[06 会話を続ける](06-continue.md)） | 会話の保存後 |
| 準備・調整 | キャラクター・場面・文体などを設定する欄の表示を切り替えます（[04](04-prepare-characters.md)・[05](05-prepare-scene.md)） | 常に表示 |

- 画面の幅が広い場合、「準備・調整」の欄は会話の右側に並んで表示され、表示したまま会話を続けることが可能です。欄の見出しにあるピンを選択すると、欄の外を選択しても表示が維持され、次回の起動時も表示された状態となります。
- 「クイック設定」と「状態」の欄は、画面の右側から重なる形で表示されます。欄の外または × を選択すると、表示が終了します。

### 会話の開始前の画面

会話の開始前は、画面中央に「新しい会話を開始」と会話の開始までの 3 つの手順が表示されます。いずれの手順を選択しても「準備・調整」の欄が表示され、キャラクターを選択すると、1 つ目の手順の番号が強調表示に変わります。

![会話の開始前の画面](../images/ja/01-03-first-view.png)

既定の会話設定プリセットが未設定の場合は、起動時に「準備・調整」の欄が自動的に表示されます。既定の会話設定プリセットは、「設定」の「AI と接続」で設定します（[08 設定](08-settings.md)）。

## 4. デザインと明るさの変更

「設定」の「一般」にある「見た目」では、画面のデザインと明るさを変更します。選択した時点で保存され、画面にもただちに反映されます。

![見た目の設定](../images/ja/02-03-appearance.png)

- **デザイン**: 「ミニマル」「和モダン」「すりガラス」の 3 種類から選択します。
- **明るさ**: 「ダーク」「ライト」「端末に合わせる」から選択します。デザインを変更した場合も、明るさの設定は維持されます。

本マニュアルの画面写真は、「和モダン」の「ダーク」で撮影しております。

## 画面を読み込めなかった場合

AlSlime を新しい版へ更新した後、表示中のブラウザで「素材」や「設定」を選択すると、「画面を読み込めませんでした。アプリが更新された可能性があります。再読み込みしてください。」と表示される場合があります。その際は「再読み込み」を選択すると、最新の画面が読み込まれます。

再読み込みの後も以前の画面が表示される場合の対処は、[14 困ったとき](14-troubleshooting.md) にてご案内いたします。
