## 1. データフォルダ

AlSlime は、設定や会話履歴を「データフォルダ」に保存します。

- 環境変数 `WORKSPACE_ROOT` を指定した場合は、そのフォルダがデータフォルダになります。指定が無い場合は、AlSlime を起動した時点の作業フォルダ（端末から起動した場合は、実行時に端末で開いているフォルダ）です。
- Windows で `start-alslime.bat` から起動した場合は、`start-alslime.bat` のあるフォルダ（AlSlime を展開したフォルダ）がデータフォルダになります。
- 本体を更新して再起動した後も、同じデータフォルダが引き続き用いられます。
- 現在のデータフォルダは、設定の「起動・システム」の「システム診断」の「ビルド情報」で確認します（[08 設定](08-settings.md)）。

データフォルダの主な中身は次のとおりです。

| 場所 | 内容 |
| --- | --- |
| `roleplay/` | キャラクターなどの設定ファイル、プリセット、会話履歴、読み上げの音声 |
| `modules/` | 支援者機能のモジュール |
| `configgen_workspace/` | 設定の自動作成（素材づくりの「AI で作る」）の作業場所 |
| 直下の指示ファイル | 各 AI の CLI が読む AI 向けの基本指示のファイル |

生成した画像は、データフォルダではなく、ホームフォルダ（OS のユーザーごとのフォルダ）の `.gemini/tmp/<識別名>/chats/images/` に保存されます。

## 2. 共有から除外する情報

`roleplay/auth/` には、API 接続先の API キー、API サービスのトークン、支援者機能のログインの情報などの秘密の情報が保存されます。

- 設定パックには、これらの情報は含まれません。
- データフォルダをフォルダごと複製すると、`roleplay/auth/` も含まれます。データフォルダを他の人へ提供する場合や共有の場所へ保存する場合は、`roleplay/auth/` を除外します。

## 3. 設定ファイルの直接の編集

キャラクターや世界観などの設定ファイル（Markdown 形式）は、テキストエディタで直接編集することも可能です。サブフォルダを作成して整理することも可能です。

~~設定ファイルの種類ごとの置き場所と、選択肢に表示される条件は、AlSlime のホームページにてご案内しております。~~（現在鋭意作成中）

AlSlime の中での編集は、素材づくりの「設定ファイル」タブで行います（[07-1 素材づくり：設定ファイル](07-material-files.md)）。

## 4. バックアップと移行

| 目的 | 方法 |
| --- | --- |
| 設定だけを別の PC へ移行・共有する | 設定パックを書き出し、移行先で取り込みます（[12 設定パックと更新](12-settings-pack-update.md)） |
| すべてを保管・移行する | データフォルダをフォルダごと複製します。`roleplay/` だけでなく、直下の指示ファイル、`modules/`、`configgen_workspace/` も含めます。画像生成を用いている場合は、ホームフォルダの生成画像の保存先も複製します |

フォルダごと複製したデータには、秘密の情報が含まれます。扱いのご注意は、本章の「2. 共有から除外する情報」にてご案内いたします。
