# 09 ComfyUI 連携（画像生成・支援者向け）

[目次に戻る](../index.md)

会話の場面を AI に読んでもらい、その情景を ComfyUI に一枚の画像として描いてもらう、支援者向けの機能です。AI が演じるキャラクターとのひとときに、目に見える一場面を添えられます。

> **この機能は現在準備中です。** 提供開始まで、今しばらくお待ちください。本章でご案内する内容は、提供開始後にご利用いただけます。

## 会話の一場面を、そのまま背景へ

AlSlime では、キャラクターとの会話の流れから今の場面を読み取り、ComfyUI で一枚の画像にできます。完成した画像は返答に添えて残せるほか、そのセッションの背景としてお楽しみいただけます。

![夏祭りの場面を背景にした会話画面](../images/ja/09-00-comfyui-chat-result.png)

言葉を交わしてきたひとときに、その場の景色がそっと加わります。この章では、お好みのキャラクターや場面に合った画像を生成し、この画面を楽しめるようになるまでの準備をご案内します。

## この章でご案内すること

1. ComfyUI と AlSlime の役割を知る
2. ComfyUI との接続を確かめる
3. ワークフローテンプレートとタグ判定 AI を設定する
4. キャラクターや場面の設定を整える
5. テスト生成で仕上がりを確かめる
6. 会話から画像を生成する

## はじめに

画像を実際に生成するのは ComfyUI です。AlSlime は、AI に会話の流れを読んでもらい、キャラクターや場面に合うプロンプトと LoRA を整えてから、ComfyUI へ生成をお願いします。完成した画像は AlSlime が受け取り、会話の該当メッセージに添えて表示します。

そのため、使用するワークフローは、あらかじめ **ComfyUI だけでも問題なく画像を生成できる状態**にしておいてください。ワークフローに必要なモデル、LoRA、カスタムノードは ComfyUI 側へご用意いただきます。

### 前提条件

- [08 支援者機能](08-sponsor.md)の手順を済ませ、ComfyUI 連携モジュールが「有効（サイドカー動作中）」になっていること
- ComfyUI 本体がご自身の環境に導入済みで、起動していること
- 使用するワークフロー、モデル、LoRA、カスタムノードが ComfyUI で利用できること
- タグ判定に使用する AI CLI が導入・認証済みであること

ComfyUI の準備がお済みでない場合は、次の公式日本語ガイドをご覧ください。

- [ComfyUI のシステム要件](https://docs.comfy.org/ja/installation/system_requirements)
- [Comfy Desktop の Windows 版](https://docs.comfy.org/ja/installation/desktop/windows)
- [ComfyUI ポータブル版（Windows）](https://docs.comfy.org/ja/installation/comfyui_portable_windows)
- [初めての画像生成](https://docs.comfy.org/ja/get_started/first_generation)
- [カスタムノードのインストール](https://docs.comfy.org/ja/installation/install_custom_node)

## 1. まずはひととおり準備する

初めてお使いになるときは、次の順で進めていただくと分かりやすいでしょう。

1. [08 支援者機能](08-sponsor.md)の案内に沿って、ComfyUI 連携モジュールをダウンロードします。モジュールの取得が完了すると、汎用ワークフロー「AlSlime Generic Workflow」が AlSlime へ自動で配置されるとともに、同じワークフローの JSON ファイルがブラウザのダウンロード先へ保存されます。
2. ブラウザへ保存されたワークフローを ComfyUI で開き、必要なモデル、LoRA、カスタムノードを揃えて一度画像を生成します。
3. [07 設定のインポート / エクスポート](07-settings-pack.md)から、画像生成用の公式サンプルを取り込みます。
4. AlSlime の「画像生成設定」で、ComfyUI との接続を確かめます。
5. キャラクター画像生成設定を整えます。
6. 「画像生成テスト」で仕上がりを確かめます。
7. 会話に戻り、AI の応答にある「画像生成」からお試しください。

現在の公式サンプルには、画像生成を始めるためのタグ判定指示ファイルが含まれます。まずはサンプルのまま動きを確かめてから、お好みに合わせて少しずつ整えていただけます。

## 2. ComfyUI と接続する

開き方: 設定（歯車）→「画像生成設定」。

「画像生成設定」は、支援者機能と ComfyUI 連携モジュールが有効な場合に表示されます。

![ComfyUI 画像生成設定](../images/ja/09-01-comfyui-settings.png)

1. 「接続設定」に、起動中の ComfyUI の URL をご入力ください。初期値は `http://127.0.0.1:8188` です。
2. 「テスト」を選び、「接続できました。」と表示されることをお確かめください。
3. 画面下部の「保存」を選びます。

同じ PC で通常の設定のまま ComfyUI をお使いなら、初期値のままで接続できます。接続先やポートを変更している場合は、ComfyUI 側と同じ URL をご指定ください。

## 3. ワークフローを確認する

ComfyUI 連携モジュールを取得すると、「AlSlime Generic Workflow」が自動的に用意されます。同じワークフローの JSON ファイルも、ブラウザのダウンロード先へ保存されます。

保存された JSON ファイルを ComfyUI の画面へドラッグ＆ドロップすると、ワークフローを簡単に開けます。ワークフローに設定されているモデルやカスタムノードが ComfyUI に揃っていることを確かめ、ComfyUI だけで一枚生成できる状態に整えてください。

> **必ず、AlSlime で画像生成を始める前に、ComfyUI でワークフローを一度開いてご確認ください。**
>
> ワークフローに設定されているモデルやカスタムノードが一つでも不足している場合、画像は生成できません。この確認を行わずに AlSlime から画像生成を試すと、生成に失敗します。

ファイルをもう一度保存したい場合は、「画像生成設定」→「ワークフロー設定」で「AlSlime Generic Workflow」を選び、隣にあるダウンロードアイコンをご利用いただけます。

ご自身で作成したワークフローを使用する場合は、[独自ワークフローを用意する](09-comfyui-custom-workflow.md)をご覧ください。

## 4. タグ判定 AI を選ぶ

「画像生成設定」→「タグ判定プロンプト設定」では、会話の流れを読み、画像に必要な内容を考えてもらう AI を選べます。

1. **タグ判定プロンプト形式**を選びます。
   - **Danbooruタグのみ**: タグを中心に扱う一般的なワークフロー向けです。
   - **自然言語混在（Anima等向け）**: 自然な文章も受け取れるモデルやワークフロー向けです。
2. **分析AI**で、Gemini CLI、Claude Code CLI、Antigravity CLI のいずれかを選びます。
3. **分析モデル**を選びます。Claude Code CLI では、必要に応じて effort も指定できます。
4. 必要な場合だけ「タグ判定タイムアウト（秒）」を調整し、最後に「保存」を選びます。

選んだ AI CLI は、あらかじめ導入とログインをお済ませください。準備については、[01 導入とセットアップ](01-setup.md)でご案内しています。

ここで選ぶ「分析AI」は、会話を読んで場面を整理する役目です。画像を実際に描くモデルは、ComfyUI のワークフローで選んでいるモデルです。

画像生成モデルは、「自然言語混在（Anima等向け）」では Anima、「Danbooruタグのみ」では Illustrious をおすすめします。AlSlime では、会話の情景を自然な文章でも伝えやすい Anima の利用をおすすめしています。

各形式の違いやタグ判定指示を調整したい場合は、[画像生成設定の詳細](09-comfyui-settings-details.md)をご覧ください。

## 5. キャラクター画像生成設定を整える

キャラクターの見た目や衣装、使用する LoRA を登録しておくと、会話の相手らしい画像に仕上げやすくなります。

開き方は、次のどちらでもかまいません。

- 会話設定サイドバーにある、キャラクター枠の画像アイコン
- 設定（歯車）→「画像生成設定」→「キャラクター画像生成設定」

キャラクター名や外見、衣装、使用する LoRA を入力し、「保存」を選びます。迷う項目は空欄のままでもお試しいただけます。

項目ごとの使い方や、場面に応じた設定を加えたい場合は、[画像生成設定の詳細](09-comfyui-settings-details.md)をご覧ください。

## 6. テスト生成で確かめる

会話から生成する前に、「画像生成テスト」で一枚試しておくと安心です。

![画像生成テスト](../images/ja/09-04-generate-test.png)

1. 使用するワークフローテンプレートを選びます。
2. 画像にしたいキャラクターを選びます。
3. 「生成」を選びます。
4. 「生成結果」をご確認ください。

仕上がりを変えてもう一枚試したいときは、「再生成」もお使いいただけます。

## 7. 会話から画像を生成する

準備が整いましたら、会話へ戻って実際の場面を描いてもらいましょう。

1. AI の応答メッセージにある「画像生成」を選びます。
2. タグ判定 AI が、その応答までの会話を読み、場面に合う内容を整えます。
3. AlSlime がキャラクター設定などを重ね、ComfyUI へ生成をお願いします。
4. 完成した画像が、選んだ応答メッセージに添えて表示されます。

![メッセージの画像生成](../images/ja/09-03-chat-pocket-watch.png)

生成中はボタンの表示が「生成中...」に変わります。そのまま少しお待ちください。画像をクリックすると大きく表示でき、ポジティブプロンプトの確認や、背景画像としての指定も行えます。

生成した画像は会話セッションとメッセージに結び付けて保存されるため、同じセッションを開き直したときにも表示されます。

## 8. 生成した画像を背景にする

画像付きの応答が表示されている間、その画像を会話画面の背景にできます。

設定（歯車）→「画像生成設定」の下部にある「セッション内背景画像」で、次の項目を調整できます。

- 背景画像を表示するか
- 画像の透明度
- 画面を埋めるように表示するか、画像全体を収めるか
- 履歴欄だけに表示するか、チャット欄まで広げるか
- チャット欄まで広げたときの入力欄の透明度

![セッション内背景画像の表示設定](../images/ja/09-05-background-settings.png)

お好みの表示に整えたら、画面下部の「保存」を選びます。

保存すると、生成した画像が会話の背景に表示されます。背景画像とメッセージの見やすさを確かめながら、お好みに合わせて透明度を整えてください。

![生成画像を背景にした会話画面](../images/ja/09-06-background-chat.png)

一つのメッセージに複数の画像がある場合は、拡大表示から「この画像を背景に設定」を選ぶと、お好みの一枚を背景にできます。

## 9. 設定を残しておく

整えた画像生成設定は、[07 設定のインポート / エクスポート](07-settings-pack.md)の「画像生成設定」として書き出せます。設定を育てていく際の控えや、別の PC へ移す際にご利用ください。

ComfyUI 本体のモデル、LoRA、カスタムノードは設定パックに含まれません。必要なファイルは、ComfyUI 側でも別に保管してください。

## うまくいかないとき

- **「画像生成設定」が見当たらない**: [08 支援者機能](08-sponsor.md)を開き、ComfyUI 連携モジュールが「有効（サイドカー動作中）」になっているかお確かめください。配置直後は AlSlime の再起動が必要です。
- **接続テストに失敗する**: ComfyUI が起動しているか、接続 URL とポートが ComfyUI 側と同じかをご確認ください。
- **独自のワークフローを登録できない**: [独自ワークフローを用意する](09-comfyui-custom-workflow.md)で、保存形式と登録手順をご確認ください。
- **ノードやモデルのエラーが表示される**: ワークフローで使用するモデル、LoRA、カスタムノードが ComfyUI 側に揃っているかお確かめください。
- **タグ判定で止まる**: 選んだ AI CLI を単独で起動できるか、ログインが済んでいるかをご確認ください。
- **生成に時間がかかる**: タグ判定 AI の待ち時間と、ComfyUI の画像生成の待ち時間は別々です。画面の表示と ComfyUI の実行状況をあわせてご覧ください。
- そのほかについては、[11 困ったときは](11-troubleshooting.md)をご覧ください。
