## 1. 設定パックの概要

設定パックは、キャラクターやテンプレート、プリセットなどの設定ファイルを ZIP 形式の 1 つのファイルにまとめたものです。別の PC への移行や設定の共有に用います。

設定パックの操作は、設定の「公式サンプル」の「設定パック」で行います。設定の「アカウント」の「管理」にある「設定パック」の「開く」で表示する窓でも、同じ操作を行います。

設定パックには、次の設定は含まれません。

- 見た目などの表示の設定
- ComfyUI と読み上げの接続設定、LoRA の置き場所の設定
- 起動の設定
- API 接続先の API キー（接続先の情報は含まれます）

新しい形式で書き出した設定パックは、古い版の AlSlime では取り込みの対象外となる場合があります。~~設定パックの容量の上限などの詳細は、AlSlime のホームページにてご案内しております。~~（現在鋭意作成中）

## 2. 設定パックの書き出し

1. 「設定パック」で「エクスポート」を選択します。
2. 「書き出す設定の選択」で対象の種類を選択します。「すべて選択」「選択解除」でまとめて切り替えます。

   ![書き出す設定の選択](../images/ja/12-02-export-select.png)

3. 必要に応じて、「キャラクター画像を含める」を有効にし、「パック名（任意）」を入力します。キャラクター画像を含めると、ファイルの容量が大きくなります。
4. 「エクスポート（zip をダウンロード）」を選択します。設定パックがブラウザのダウンロードに保存されます。

   ![書き出しの実行](../images/ja/12-03-export-run.png)

画像生成の設定の種類は、支援者機能の画像生成が有効な場合に表示されます。

## 3. 設定パックの取り込み

![インポート](../images/ja/12-01-import.png)

1. 「設定パック」で「インポート」を選択します。
2. 「パックファイル（zip）を選択」を選択し、設定パックを指定します。枠への ZIP ファイルのドラッグ＆ドロップでも指定が可能です。
3. 「取り込みプラン」に、取り込むファイルの一覧と新規・衝突・スキップの件数が表示されます。内容を確認します。

   ![取り込みプラン](../images/ja/12-04-import-plan.png)

4. 「既存ファイルと衝突した場合」で、同じ名前のファイルがすでにある場合の扱いを選択します。

   | 選択肢 | 内容 |
   | --- | --- |
   | スキップ（既存を残す） | 既存のファイルを残し、取り込みません |
   | 上書き | 既存のファイルを設定パックの内容で置き換えます |
   | リネームして追加 | 名前を変えて、別のファイルとして追加します |

   ファイルごとに扱いを変える場合は、一覧の各行で選択します。「一括設定に従う」の行は、「既存ファイルと衝突した場合」の選択に従います。

5. 「取り込み実行」を選択します。

一覧で「常に上書き」と表示されるファイル（AI プロバイダ指示ファイルと API 接続設定・指示ファイル）は、衝突した場合の選択に関係なく上書きされます。

### 起動時の自動取り込み

データフォルダ内の `roleplay/import_inbox/` に設定パックを保存すると、次回の起動時に新しいファイルだけが自動的に取り込まれます。既存のファイルは変更されません。その起動で取り込んだ設定パックは、「インポート」の「起動時の自動取り込み」に表示されます。

## 4. 公式サンプルとテンプレートパック

- **公式サンプル**: キャラクター・テンプレート・プリセットの一式です。設定の「公式サンプル」の「設定サンプル一式」で取り込みます。設定パックの窓の「インポート」の「公式サンプル」で「サンプルをダウンロードして取り込み」を選択しても、同じ一式が取り込まれます。既存のファイルは変更されません。手順は [01 導入と起動](01-setup.md) にてご案内いたします。
- **テンプレートパック**: 設定ファイルのテンプレートと設定自動生成の指示の一式です。設定の「公式サンプル」の「設定自動生成用テンプレート」（[08 設定](08-settings.md)）、または素材づくりの「設定ファイル」タブ（[07-1 素材づくり：設定ファイル](07-material-files.md)）で取り込みます。

## 5. 本体の更新

### 更新の確認

AlSlime は、起動時に新しい版の有無を確認します。設定の「起動・システム」の「更新を確認」で、任意の時点に確認することも可能です。起動時の確認は、「起動時に更新を自動確認する」で無効にします（[08 設定](08-settings.md)）。

### 更新の告知

新しい版がある場合は、現在の版と最新の版、更新の内容が表示されます。

![更新の告知](../images/ja/12-05-update-notice.png)

| ボタン | 内容 |
| --- | --- |
| 今すぐ更新 | AlSlime の中で更新を行います。Windows の場合に表示されます |
| ダウンロードページを開く | 配布のページを表示します。Linux の場合は、配布のページから新しい版を取得します |
| 後で | その日は告知を表示しません |
| このバージョンの告知をスキップ | この版の告知を今後表示しません |

「今すぐ更新」を選択すると、新しい版のダウンロードと置き換えが行われ、AlSlime が自動的に再起動します。画面は自動的に再接続されます。会話の応答など、実行中の処理がある場合は、更新は開始されません。処理の完了後に改めて選択します。

### 支援者機能のモジュールの更新

支援者機能のモジュールにも更新がある場合は、告知にモジュールの行が加わり、「一括全更新」と「本体のみを更新」が表示されます。

- **一括全更新**: 本体の更新後の起動で、モジュールも更新されます。更新中は、画面の上部に案内の帯が表示されます。帯が表示されている間も、操作は可能です。
- **本体のみを更新**: 本体だけを更新します。

モジュールの行ごとに、「更新」「後で」「この更新の告知をスキップ」のいずれかを選択します。モジュールだけに更新がある場合は、告知の題が「モジュールの更新があります」になります。

更新の後に画面が正しく表示されない場合の対処は、[02 画面の見かた](02-screen.md) の「画面を読み込めなかった場合」にてご案内いたします。
