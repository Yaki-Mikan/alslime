# 独自ワークフローを用意する

普段お使いの ComfyUI ワークフローを、AlSlime の画像生成にもご利用いただけます。

この別紙では、ワークフローへ置換文字列を加え、AlSlime に登録するまでをご案内します。公式の「AlSlime Generic Workflow」をそのままお使いになる場合は、この準備は必要ありません。

## ComfyUI で動作を確かめる

はじめに、使用するワークフローを ComfyUI で開き、通常どおり画像を生成できることをお確かめください。

ワークフローで使用するモデル、LoRA、カスタムノードは、ComfyUI 側へご用意いただきます。

## 置換文字列を加える

独自のワークフローにも、会話から読み取ったキャラクターや場面を反映できます。

ComfyUI でワークフローを開き、画像生成に使用しているポジティブプロンプトへ、次の内容を加えます。

```text
__CHARACTER__, __FEATURES__, __OUTFIT__, __EMOTION__, __POSE__, __COMPOSITION__, __ACTION__, __BODYSTATE__, __LOCATION__, __RATING__, __QUALITY_EXTRA__, __EXTRA_POSITIVE__
```

ネガティブプロンプトには、次の内容を加えます。

```text
__EXTRA_NEGATIVE__, __TAG_NEGATIVES__
```

普段お使いの品質指定や画風のプロンプトは、そのまま残していただけます。

## API 形式で保存する

準備が整いましたら、AlSlime へ登録するための JSON ファイルを保存します。

1. ComfyUI の画面左上にある「グラフ」を開きます。
2. 「エクスポート（API）」を選びます。
3. ブラウザへダウンロードされた JSON ファイルを保存します。

![ComfyUIでワークフローをAPI形式として保存する操作](../images/ja/09-07-comfyui-export-api-workflow.png)

ComfyUI の版や表示言語によっては、「Export (API)」または「Save (API Format)」と表示されます。

## AlSlime に登録する

1. 設定（歯車）→「画像生成設定」を開きます。
2. 「ワークフロー設定」を開きます。
3. 保存した JSON ファイルを枠内へドラッグ＆ドロップするか、枠を選んでファイルを開きます。
4. 分かりやすい名前を入力し、「追加」を選びます。
5. 画像生成に使うワークフローを選び、画面下部の「保存」を選びます。

登録できましたら、「画像生成テスト」で一枚お試しください。

## 置換文字列の一覧

| 置換文字列 | 反映される内容 |
| --- | --- |
| `__CHARACTER__` | キャラクター名、作品名、キャラクタープロンプト、LoRA のトリガーワード |
| `__FEATURES__` | 髪型、髪色、目の色などの身体的特徴 |
| `__OUTFIT__` | 現在の服装 |
| `__EMOTION__` | 表情や感情 |
| `__POSE__` | 姿勢 |
| `__COMPOSITION__` | 構図やカメラの向き |
| `__ACTION__` | キャラクターの行動 |
| `__BODYSTATE__` | その場面での身体の状態 |
| `__LOCATION__` | 場所や背景 |
| `__EXTRA_POSITIVE__` | キャラクター画像生成設定の「追加ポジティブ」 |
| `__EXTRA_NEGATIVE__` | キャラクター画像生成設定の「追加ネガティブ」 |
| `__TAG_NEGATIVES__` | 選ばれたタグマッピングのネガティブプロンプト |
| `__RATING__` | 生成プロファイルで指定した内容 |
| `__QUALITY_EXTRA__` | 生成プロファイルやプレースホルダプリセットで指定した内容 |

置換文字列は、`{{POSE}}` のように記すこともできます。本書では `__POSE__` の形式でご案内しています。

## LoRA を使う

標準の `CheckpointLoaderSimple`、または `UNETLoader` と `CLIPLoader` を使用するワークフローでは、AlSlime で選んだ LoRA が適用されます。

独自のモデル読み込みノードで LoRA が反映されない場合は、普段使用する LoRA をワークフロー側へ組み込んだ状態でお試しください。

## 複数のワークフローを使う

ワークフローは複数登録できます。普段使うものは、「ワークフロー選択」で選んで保存します。

場面に応じて使い分けたい場合は、[画像生成設定の詳細](09-comfyui-settings-details.md)もご覧ください。
