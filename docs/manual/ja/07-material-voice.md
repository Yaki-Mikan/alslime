# 07-4 素材づくり：声

[目次に戻る](../index.md) ／ [07 素材づくり](07-material.md)

前章: [07-3 素材づくり：キャラ](07-material-characters.md) ／ 次章: [07-5 素材づくり：タグと画像生成](07-material-image.md)

本章では、素材づくりの「声」タブで行う声の登録と読み上げのテストについてご案内いたします。「声」タブは、支援者機能の読み上げが有効な場合に表示されます。読み上げは日本語の表示言語でのみ利用可能な機能です。

## この章の内容

1. 画面の構成
2. 登録済みの声
3. Latent 生成
4. 参照音声・Latent の直接アップロード
5. 読み上げテスト

## 1. 画面の構成

![声のタブ](../images/ja/07-4-01-voice.png)

画面の幅が広い場合は、左に「ボイス登録・管理」、右に「読み上げテスト」が並びます。画面の幅が狭い場合は、上下に並びます。「ボイス登録・管理」は、見出しを選択すると内容の表示が切り替わります。

## 2. 登録済みの声

- **直近の登録音声**: 登録したばかりの声が表示され、すぐに試聴することが可能です。
- **登録Voice一覧**: 見出しを選択すると、読み上げサーバーに登録済みの声の一覧が表示されます。見出しの横には件数が表示されます。

  一覧では、Voice ID による検索、試聴、削除が可能です。声を削除する際は、その声を紐づけているキャラクターが表示されます。

  「再読込」で一覧が最新の状態に更新されます。

## 3. Latent 生成

「Latent生成」では、参照音声（.wav）の声の特徴を表すファイル（Latent）を作成し、声として登録します。この機能は、Latent の生成に対応した読み上げサーバーを接続している場合に利用可能です。

1. Voice ID（半角英数）と表示名を入力し、「ファイルを選択」で参照音声を指定します。参照音声は、点線の枠へのドラッグ＆ドロップでも指定が可能です。
2. 必要に応じて、使用する範囲（開始秒・終了秒）、変換デバイス、変換精度、音量正規化を指定します。
3. 「Latentを生成して登録」を選択すると、声として登録されます。「Latentを生成してダウンロード」を選択すると、作成したファイルがパソコンに保存されます。

作成済みの Latent ファイル（.pt・.pth）を枠へドラッグ＆ドロップした場合は、変換を行わずに登録します。

## 4. 参照音声・Latent の直接アップロード

Voice ID を入力し、「ファイルを選択」で参照音声または Latent ファイルを指定して「登録」を選択すると、声として登録されます。

- 対応形式は、wav・flac・mp3・m4a・ogg・opus・aac・webm です。Latent の直接登録に対応した読み上げサーバーでは、pt・pth も指定が可能です。
- 参照音声の長さの上限は、合計 120 秒です（読み上げモデルが v4-Small の場合）。

## 5. 読み上げテスト

「読み上げテスト」では、登録した声で文章を読み上げ、仕上がりを確認します。

1. 「テスト用テキスト」に、読み上げる文章を入力します。この文章は、登録Voice一覧の試聴にも用いられます。
2. 「テストする音声」で、声を紐づけたキャラクターまたは登録済みの声を選択します。キャラクターを選択した場合は、そのキャラクターの紐づけの設定で読み上げます。
3. 「テスト」を選択すると、音声の作成が始まります。作成中は「キャンセル」で中止します。
4. 作成が完了したら、「再生」で再生します。

声をキャラクターに紐づける方法は、[07-3 素材づくり：キャラ](07-material-characters.md)、読み上げの設定は [11 読み上げ](11-tts.md) にてご案内いたします。
