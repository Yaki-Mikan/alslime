# 06 設定自動生成

[目次に戻る](../index.md)

キャラクター名や作品名をもとに、AIにキャラクター設定を作成してもらえます。現在は、キャラクター設定に対応しています。

## 1. 設定自動生成を開く

1. ヘッダーのノートアイコンを選びます。
2. 画面上部の「設定自動生成」を開きます。

![設定自動生成画面](../images/ja/06-01-config-auto-generation.png)

## 2. 作成内容を入力する

1. 種別が「キャラクター」になっていることを確かめます。
2. 「キャラクター名」と「作品名」を入力します。
3. 加えたい内容がある場合は、「設定作成備考」に記します。
4. 使用するAIプロバイダとモデルを選びます。

## 3. 作成方法を選ぶ

- **じっくり作成（2段階）**: AIがまとめた調査メモを確認してから、設定作成へ進みます。途中で内容を調整したい場合にお選びください。
- **一括作成**: 調査から設定作成までを続けて行います。途中の確認が不要な場合にお選びください。

「じっくり作成（2段階）」では、はじめに「1段階目（調査）を実行」を選びます。調査メモを確認したら、「2段階目（設定作成）を実行」へ進みます。

「一括作成」では、作成方式を切り替えてから「実行」を選びます。

作成中は、画面右側の「AIの作業経過」で進み具合を確認できます。画面を閉じたあとも、作成はそのまま続きます。

## 4. 完成した設定を確認する

作成が終わりましたら、「設定ファイルを編集」を選びます。内容をご確認のうえ、お好みに合わせて整えてから会話にお使いください。

> **設定自動生成は試験提供中の機能です。**
>
> AIが作成した内容には、誤りや意図と異なる設定が含まれることがあります。会話で使用する前に、必ず内容をご確認ください。
>
> AntigravityのFlashモデルでは、約2分で完了した例を確認しています。Claudeでは数十分かかる場合があり、使用量制限を大きく消費することがあります。作成時間は、内容や利用環境によって変わります。
