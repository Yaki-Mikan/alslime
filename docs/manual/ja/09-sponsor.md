# 09 支援者機能

本章では、GitHub Sponsors で AlSlime を支援しているユーザー向けの機能について、ログインの方法と機能のモジュールの管理をご案内いたします。

## この章の内容

3. ログイン後の画面

5. ログアウト

## 1. 支援者機能の概要

GitHub Sponsors で支援中のアカウントでログインすると、次の機能が有効になります。

| 機能 | 内容 | 詳細 |
| --- | --- | --- |
| 画像生成 | 会話の場面や表情画像を ComfyUI または API サービスで生成します | [10 画像生成](10-image-generation.md) |
| 行動の選択肢 | 応答の下に、次の行動の候補を表示します | [03 はじめての会話](03-first-chat.md) |
| 読み上げ | キャラクターの発言を声を付けて読み上げます（表示言語が日本語の場合） | [11 読み上げ](11-tts.md) |

支援者機能の操作は、設定の「アカウント」の「支援者機能」の欄で行います。

## 2. ログイン

![未ログインの状態](../images/ja/09-01-not-logged-in.png)

1. 設定の「アカウント」を表示します。
2. 「GitHub でログイン」を選択します。ブラウザの別のタブで GitHub の画面が表示されます。
3. GitHub の画面で支援中のアカウントにログインし、AlSlime の連携を承認します。

ログインの手続き中は、AlSlime の画面に「ブラウザでログインを完了してください...」と手続きの期限が表示されます。

![ログインの手続き中](../images/ja/09-02-login-waiting.png)

- GitHub の画面が表示されない場合は「開かない場合はこちら」を選択します。別のブラウザでログインする場合は、このリンクのアドレスをコピーして開きます。
- 手続きが完了すると、AlSlime の画面に自動的に反映されます。
- 期限を過ぎた場合は、改めて「GitHub でログイン」を選択します。

「支援者になる」を選択すると、GitHub Sponsors の支援のページが表示されます。

## 3. ログイン後の画面

![ログイン後の状態](../images/ja/09-03-active.png)

- 状態の札には「有効」などの状態とプラン名、期限が表示されます。
- 開発者からのお知らせがある場合は、その内容が表示されます。
- 「状態を更新」を選択すると、支援の状態を改めて取得します。支援を始めた直後やプランを変更した後に用います。

## 4. モジュールの取得と管理

支援者機能の一部は、モジュールと呼ぶ追加のプログラムで動作します。モジュールごとに、状態（「未配置」「配置済み」「有効」など）が表示されます。

| モジュール | 内容 |
| --- | --- |
| 画像生成連携モジュール | 画像生成の機能を提供します。取得すると、付属のサンプルワークフローも配置されます |
| 行動選択肢モジュール | 行動の選択肢の機能を提供します |
| Irodori-TTS連携モジュール | 読み上げの機能を提供します。表示言語が日本語の場合に表示されます |

- **モジュールをダウンロード**: モジュールを取得して配置します。多くの場合、取得した時点で有効になります。有効にならない場合は、AlSlime を再起動します。
- **更新**: 新しい版のモジュールがある場合に表示されます。選択するとモジュールが更新されます。
- **クリーン再導入**: モジュールと配布のサンプルワークフローを削除してから、改めて配置します。動作が不安定な場合に用います。配布物と同じ名前のテンプレートを編集していた場合は、その内容も削除されます。

画像生成連携モジュールを取得すると、付属のサンプルワークフローの JSON ファイルがブラウザのダウンロードにも保存されます。保存できなかった場合は、素材づくりの「画像生成」タブの「書き出す」で改めて保存します（[07-5 素材づくり：タグと画像生成](07-material-image.md)）。

> **読み上げのご注意**
>
> - Irodori-TTS-Server は外部のツールで、ご自身での構築と起動が必要です。
> - GPU の使用を推奨します。必要な VRAM の容量は使用するモデルによって異なります。VRAM の容量が少ない環境向けには、量子化版が用意されています。モデルと量子化版の情報は [Irodori-TTS-v4-Small の配布ページ](https://huggingface.co/Aratako/Irodori-TTS-v4-Small) で確認します。
> - 画像生成（ComfyUI）と同時に使用すると、両方の処理が VRAM を使用するため、メモリ不足になる場合があります。
> - 音声モデルの倫理的な制約として、無断の音声クローン・なりすまし・ディープフェイクへの使用は禁止されています。

モジュールの更新の確認は、設定の「起動・システム」の「更新を確認」でも行います（[12 設定パックと更新](12-settings-pack-update.md)）。

## 5. ログアウト

「ログアウト」を選択すると、支援者機能のログインが解除され、未ログインの状態に切り替わります。
