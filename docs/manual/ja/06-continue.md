# 06 会話を続ける

[目次に戻る](../index.md)

前章: [05 準備・調整：場面・文体・プリセット](05-prepare-scene.md) ／ 次章: [07 素材づくり](07-material.md)

本章では、会話を始めた後に行う操作として、変更した設定の反映、新しい会話の開始、状態の欄、履歴、ジョブ進行状況についてご案内いたします。

## この章の内容

1. 会話ごとの設定の保存
2. 欄の下部のボタン
3. 送信時の設定変更の確認
4. 状態の欄
5. 履歴
6. ジョブ進行状況

## 1. 会話ごとの設定の保存

「準備・調整」の欄の設定は、会話ごとに保存されます。履歴から会話を再開すると、その会話に保存されている設定が欄に復元されます。

会話中に欄の設定を変更した場合、その変更は「変更を反映」を選択した時点で会話に保存されます。反映していない変更がある状態でメッセージを送信すると、「設定変更の確認」が表示されます。

## 2. 欄の下部のボタン

欄の下部には、会話の状態に応じて次のボタンが表示されます。

![欄の下部のボタン](../images/ja/06-01-bottom-buttons.png)

| ボタン | 内容 | 表示される条件 |
| --- | --- | --- |
| 会話開始 | 欄の設定で、会話を開始します | 会話の開始前 |
| 変更を反映 | 欄で変更した内容を現在の会話に保存します。保存が完了すると、2 秒ほど「反映しました」と表示されます | 会話中で、反映していない変更がある場合 |
| この設定で新しく始める | 欄の設定で、新しい会話を開始します | 会話中で、参加するキャラクターの顔ぶれを変更していない場合 |
| 〈名前〉と新しく始める | 欄の設定で、新しい会話を開始します。ボタンには参加するキャラクターの名前を「・」でつないで表示します | 会話中で、参加するキャラクターの顔ぶれを変更した場合 |

- 参加するキャラクターの顔ぶれを変更した場合は、「〈名前〉と新しく始める」が目立つ形で表示されます。この場合も、その下の「変更を反映」を選択すると、キャラクターの変更が現在の会話に保存されます。
- キャラクターの並び順の変更のみでは、顔ぶれの変更として扱われません。
- 新しい会話を開始した後も、それまでの会話は履歴に保存されています。

## 3. 送信時の設定変更の確認

会話中に反映していない設定の変更がある状態でメッセージを送信すると、「設定変更の確認」が表示されます。準備・調整の欄での変更と状態の欄での変更が対象です。

![設定変更の確認](../images/ja/06-02-apply-confirm.png)

| ボタン | 内容 |
| --- | --- |
| 反映して送信 | 変更を現在の会話に保存してから、メッセージを送信します。保存に失敗した場合は「セッションへの反映に失敗しました」と表示され、送信は中止されます |
| 反映せずに送信 | 会話に保存されている設定のまま、メッセージを送信します。欄の変更は、反映していない状態で残ります |
| キャンセル | 送信を取りやめます |

- 「このセッションでは今後この確認を表示しない」を選択した状態で送信すると、その会話では以降この確認が表示されなくなります。変更の保存は、「変更を反映」で行います。
- 会話中に会話設定プリセットを読み込んだ場合の扱いは、[05 準備・調整：場面・文体・プリセット](05-prepare-scene.md) にてご案内しております。

## 4. 状態の欄

会話の保存後は、会話画面の見出しの「状態」を選択すると、「セッション状態」の欄が表示されます。欄には「キャラクター状態」と「セッション時刻」の 2 つの区画が並び、各区画の見出しを選択すると、内容の表示が切り替わります。欄の外または × を選択するか、Esc キーを押すと欄の表示が終了します。

![状態の欄](../images/ja/06-03-status.png)

### キャラクター状態

キャラクターごとの「〈名前〉の状態」には、個別性格設定・個別服装・髪型・個別背景、パラメータ、相関関係（対象・関係性・好感度・詳細）が表示されます。

「〈名前〉の状態」の見出しにある鉛筆のアイコンを選択すると、パラメータと相関関係（関係性・好感度・詳細）を編集する状態となります。

- 「保存」を選択すると、編集した内容が準備・調整の欄に反映されます。「キャンセル」を選択すると、編集が取り消されます。
- 同時に編集する対象は、1 人のキャラクターに限られます。
- 個別性格設定・個別服装・髪型・個別背景は表示のみです。変更は、準備・調整の欄のキャラ詳細で行います（[04 準備・調整：キャラクター](04-prepare-characters.md)）。

### セッション時刻

日付時刻を有効にした会話では、「現在のセッション時刻」「インクリメント設定時間」「次のインクリメント時間」「累積経過」が表示されます。

- 区画の見出しの右にある鉛筆のアイコンを選択すると、セッション時刻とインクリメント設定時間を編集する状態となります。詳細モードの会話では、年・月・日・秒もあわせて指定します。
- 「次のインクリメント時間」は、編集の状態にしなくても変更が可能です。次回の送信で進める時間を指定する項目で、応答が届いた時点でその値がインクリメント設定時間に置き換わります。

日付時刻の仕組みは、[05 準備・調整：場面・文体・プリセット](05-prepare-scene.md) にてご案内しております。

### 変更の反映

状態の欄で変更した内容も、準備・調整の欄と同様に、反映するまで会話には保存されません。反映していない変更がある場合は、各区画の見出しの右に保存のアイコン（「現セッションに反映」）が表示されます。このアイコンを選択すると、変更が会話に保存されます。

## 5. 履歴

切り替え列の「履歴」を選択すると、これまでの会話の一覧が表示されます。

![履歴の画面](../images/ja/06-04-history.png)

- 会話は「今月」と「それ以前」に分けて並びます。各行には、会話の題、参加しているキャラクターの名前、経過時間が表示されます。画面の幅が広い場合は、プリセット名とシチュエーション名もあわせて表示されます。
- 上部の検索欄では、会話の題・キャラクター名・プリセット名・シチュエーション名による絞り込みが可能です。
- 行を選択すると、会話の画面に切り替わり、その会話が再開されます。準備・調整の欄の設定と使う AI とモデルもその会話のものに切り替わります。応答の生成中の会話は、引き続き応答を待つ状態となります。
- 見出しの右にある「新しい会話」を選択すると、準備・調整の欄の設定が空の状態となり、会話の画面で新しい会話の準備が始まります。

### 会話の削除

1 件ずつ削除する場合は、行の右にあるゴミ箱のアイコン（「セッションを削除」）を選択し、確認の窓で「削除」を選択します。画面の幅が広い場合、アイコンは行にマウスを重ねた際に表示されます。

複数の会話をまとめて削除する場合は、次の手順で行います。

1. 見出しの右にある「まとめて削除モード」のアイコンを選択します。
2. 削除する会話の行を選択します。
3. 画面下部の「選択中: ○件」の横にある「削除」を選択し、確認の窓で「削除」を選択します。

- 確認の窓に表示されるとおり、削除の操作は元に戻せません。
- 表示中の会話を削除した場合は、新しい会話の状態に切り替わります。
- まとめて削除する際に削除に失敗した会話は、選択された状態で残ります。
- 「キャンセル」を選択すると、まとめて削除する状態が終了します。

## 6. ジョブ進行状況

AI の応答、画像生成、読み上げなどの処理は、AlSlime の本体で順番に実行されます。ブラウザを終了した場合も、処理は継続されます。

実行中の処理がある間は、会話画面の見出しに「○件実行中」と表示されます。この表示を選択すると、「ジョブ進行状況」の窓が表示されます。

![ジョブ進行状況](../images/ja/06-05-jobs.png)

- 見出しの横には、全体の同時実行数のうち使用中の数と上限が「全体: 使用中の数/上限」の形式で表示されます。
- 処理は「実行中」と「待機中」に分けて並びます。実行中の処理は「中止」、待機中の処理は「キャンセル」のアイコンで取りやめます。
- 直近に失敗した処理が、最大 3 件表示されます。
- 表示は 1.5 秒ごとに更新されます。
- × または窓の外を選択すると、窓の表示が終了します。

同時実行数の上限は、[08 設定](08-settings.md) の「同時実行数設定」で変更します。
